# 停点汇报：每次把话交回去的固定骨架

> **何时读**：**每一次把话交回给人的时候**——活干完了要报，卡住了要报，
> 对方换个话题把流程打断了也要报。
>
> **为什么要有固定模板**："说人话""别啰嗦"这类叮嘱在长指令下必失守。
> 固定骨架把合规从"记得住"变成"照着填"。

## 治什么（两种迷路，都发生在停下来的那一刻）

1. **改动静默**：出原型顺带产的规格、改某页顺带改的分册、回写正文顺带动的派生层——
   落盘了对方不知道；拿到零散编号也不知去哪个文件查。
2. **位置迷失**：会话一被打断，对方记不得流程停在哪一步、下次该谁先动，只能自己翻记录对齐。

两件事同一时刻发生，所以收在同一个骨架里。

---

## 骨架（顺序即优先级，不许重排）

> **顺序按「关注度递增」排：最要他动手的放最后。** 对话是流、视口停在末尾，
> 放前面的会被后面的段顶出视野。
> **这跟文档相反**——文档有滚动条、从上往下读，所以文档里待确认项仍然置顶。

### 1. ✅ 本轮完成 ＋ 📝 本轮变更
动过产物才写。逐文件一行，给**已解析的可点击真实路径**（别留 `{slug}` 占位），同步产物一并列全。

宣告"完成/通过"时**区分哪些是验证过的、哪些是推断的**——"过了检查"不是"合格"的替身，
推断的那部分归下面 ℹ️。

**产物正文不进对话**：需求点清单、故事、规则、字段表这类**已落盘**的内容，
对话里给 路径 + 编号 + 一句话即可，**禁整表整段重贴**——整表重贴是落盘之外的又一层成文，
而他逐条核对的地方是文件本身，不是聊天流。

### 2. 🔄 正在做
有后台 / 后续动作才写，没有则省。

### 3. ℹ️ 供您知悉（不用回复，但影响判断）
风险、诚实边界（哪些是实测的、哪些是推断的）、环境局限、被跳过或没产的东西。
**条数多就更要往上放**——它越长，越会把下面要答的事顶走。

### 4. 📍 现在在哪 ／ ⏭ 下一步
各一句。📍 = 哪个需求、走到哪一步、什么状态（**阶段说中文名，别念代号**）；
⏭ = 下次从哪续、谁先动（"您答完上面两项，我接着改报名详情页的字段口径"）。

> **📍⏭ 省不得**，这是最常见的迷路来源。**没动产物的回合也要报这两行**——
> 他要的是位置，不只是变更。

### 5. 🔴 需要您做的事（压轴，紧挨输入框）
- 有待确认项 → 按下面「弹题判据三问」处理，弹过的写「✔️ 本停点已确认 N 条」结果行。
- 文字待答形态：**第一条就是最关键那条并说明它卡住什么**；每项自表述；**≤3 条**。
- **无则显式写"无需您回复"**——让他确定不必往回翻。

**禁一切指代**：「昨天那 4 个」「那 3 项」，以及括号里塞几个短标签充当展开（「清单粒度 / 抽屉宽度」）。

> **判据**：把这条单独发给今天第一天接手的同事，他能不能直接答？答不了就把内容写进句子。

**引用产物必给可点击的已解析真实路径**——「点开需求概述页就能看到」不算定位
（那是操作指引，没说是哪个文件）。

---

## 弹题判据三问（要不要做成交互式选择题）

按序问，命中即止：

| | 问 | 命中的处置 |
|---|---|---|
| ① | **他要先去读产物才能答吗？** | 要 → **不弹**，走文字停点（可点路径 + "审完回我"）|
| ② | **不问就不能往下走吗？** | 能往下走 → **不弹**，写进待确认表，收尾汇报点名 |
| ③ | **答案会推翻已落盘的内容吗？** | 会 → **弹**，且必须在写那份内容**之前**弹 |

三问走完没命中"弹" = 不弹。

**审阅 / 放行 / 定稿类一律不弹窗**——他要先离开对话读产物才答得出，弹窗只会逼他没读就点选。
改文字停点：可点路径 + 「📋 推荐审核顺序」一行 + "审完回我通过、或点名哪条不过"。

**同一停点的题攒一批一次弹完，别逐条弹**——他的痛点是"被打断几次"，不是"答了几题"。

**强制力只管待确认、不管放行**（两类漏答方向相反）：
待确认漏答会**带着未决往前跑**，到收口才被硬拦、返工在最贵的时刻；
放行漏答只会**让流程停住**（不自推进度），不需要强制力。
把放行做成弹窗只有两种结局：他没读就点"通过"（闸变橡皮图章），或弹窗挂着等他读产物（双方空等）。

---

## 两档，按本回合动没动产物分

| | 报什么 |
|---|---|
| **动过产物 / 推进过流程** | 整套骨架 |
| **没动产物**（纯问答 / 只读查证 / 被别的话题打断）| **轻量档：📍⏭ 两行必报**，🔴 有才写，✅ 可省 |

---

## 篇幅纪律

- 停点汇报 **≤15 行**；骨架分节是**上限不是下限**。
- 根因、论证、自我复盘一律往前放，别挤在 📍⏭ 与 🔴 之间。
- 检查报错原文、选择器、token 估算一律进流水账不进回复。
- **不复述上轮背景。**
- **同一件事只说一遍**——重复本身就在稀释重点。

---

## 停点主权：球交出去了就别自己抢回来踢

你在汇报里说了"要我接着做说一声"，决定权就在对方手上了。
这时若有某个检查项催着你补活，**先答一问：这件事等他回话再做，会丢东西吗？**

- 不会丢 → 已经说过就够了，**别开工**。
- 会丢（产物写了一半、抓取产物没回流）→ 做完再停。

> 检查项只知道"有件事没做"，不知道"你已经问过他了"——它看不见你说的话，你看得见。

---

## 跨会话断点另记一笔

停点是"真要跨会话"的（他说要走 / 等客户 / 等外部输入）→ 把 📍⏭ 两句写进流水账，
下个会话读顶部即可接上，他不必复述。**普通停点不记**——每停必记会把流水写成账本。

**阶段收口停点默认在 ⏭ 里顺带建议：下一阶段换新会话起跑。** 话术必须两半理由都说：

1. **为什么换**（不换会怎样）：本会话上下文已经很长，继续跑会越来越慢，
   长到一定程度还会自动压缩记忆、细节会失真——现在正好是阶段收口，是换的最佳时点；
2. **为什么不亏**：产物全在盘上、交接靠流水账断点条目，新会话零复述接上。

只说②不说①，他读到的是"换也行不换也行"，没法判断。

---

## 发出前扫一眼

产物名带上用途、内部工序词按 `expression.md` 的表换掉。

> **为什么这一眼放在这里**：文档里的技术词还有别的检查能提醒，**对话没有**。
> 对话是全流程唯一无人把关的出口，这一眼就是它的关口。

正反例：
- ❌「我把 page_map_confirmed 翻成 true（解除画原型的拦截）」
- ✅「页面改动清单您已确认，我开始画原型」
- ❌「已过 G2/G4，review_phase 2」
- ✅「需求卡和各页规格都已确认，进入文档组装」

---

## 豁免

本会话与需求流程无关（工具维护 / 环境排障 / 无在途需求）。
