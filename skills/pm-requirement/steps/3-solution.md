# 步 3 · 方案核对

> **必读**：`../../pm-kit/rules/solution-design.md`（从哪起跳、做到哪一档）
> + `../../pm-kit/rules/item-admission.md`（拆故事的尺子）
> **产出**：`process/steps/3-solution.md` + 方案概述（落载体顶部）

**这一步是原型动笔前的最后一道**——它确认的是「改哪儿、改成什么样」，不是「怎么实现」。

---

## 1. 快速拆用户故事（尺子只有一把）

**一条 = 一个能独立走完的用户主流程。**

自检：念"作为…我要…以便…"——两条"以便"相同 → 合并；
名字里出现「Step X / 某类型 / 某控件」→ 它不是故事，细节下沉到页面说明。

**这一步拆得粗一点没关系**，它的作用是给改动清单立骨架，不是最终交付物。

---

## 2. 基准段：清单生成前先立分母

> **为什么要先立分母**：没有分母，"改动清单"就是一份想到哪写到哪的清单——
> 漏了什么没人知道，因为没有东西可对账。

基准段 = 从步 2 的影响面里抄出来的**"应该被覆盖的全集"**：

| 基准项 | 从哪来 | 核销状态 |
|---|---|---|
| {{ 确定要改的模块 / 页面 }} | 影响面一页 | ⬜ / ✅ |
| {{ 可能牵连的 }} | 影响面一页 | ⬜ / ✅（含"本期不涉及 + 理由"）|
| {{ 受控入口清单每一项 }} | 入口普查 | ⬜ / ✅ |
| {{ 存量处理 }} | 存量那一行 | ⬜ / ✅ |

**核销纪律**：
- 清单里的每一行都要能指回基准段的某一项；
- 基准段里每一项都要被清单覆盖，**或显式标"本期不涉及 + 理由"**；
- **基准段立起来之后不随意改**——真要改（发现新的波及面），
  改完要**重新走一遍核销**，并在流水里记一笔为什么改。

---

## 3. 页面 / 能力改动清单（必产，是核对的主材料）

**这是他要逐条点头的东西，也是下游规格与原型的页面台账。**

| 落点 | 类型 | 现状是什么 | 本期改成什么 | 为什么 | 承载故事 | 现状证据 |
|---|---|---|---|---|---|---|
| {{ 页名 / 能力名 }} | {{ 页面·改造 / 页面·新页 / 非页面·接口 … }} | {{ }} | {{ }} | {{ }} | {{ US-0X }} | {{ 出处，或「待实查」}} |

### 三条硬要求

1. **逐页实查，禁用一页推断其余。** "现状是什么"那一列必须有证据出处
   （见 `../../pm-kit/rules/evidence.md`）；查不到就写「待实查」，**别用确定语气**。
2. **名字要钉到真实的页 / 入口上。** 对方口中的"详情页"可能有三个意思——
   **多义就是必须澄清的信号**，不许挑一个通用义往下写。
   涉及按钮显隐 / 新增时，先列「页面 × 按钮」矩阵让他核对，矩阵确认后再展开。
3. **逐条过一遍最小增量阶梯**（`solution-design.md §三`）：
   这一条真的需要新增入口 / 新页吗？还是能在现状产物上扩展？

---

## 4. 方案概述（落载体顶部）

按 `../../pm-kit/templates/solution-overview.md` 的四节骨架写：
**背景与目标 / 方案与改动 / 用户操作主线 / 本期不做**。

> **这份东西有两个消费方**：载体文件顶部 + 原型的概述页。
> **原型那页直用这份原文，禁转写**——转写必漂移，方案层只有一个信源。

**核心逻辑等结构化内容进表格，禁散文段落。**

---

## 5. 逐页确认（G3 的实际形态）

把改动清单摆给他，**逐行确认**。这一步过了才能动原型。

请审话术要点：
- 首行说清「这是改动落点的全集，确认后我就照它画原型」；
- 每行让他答三种之一：**要做 / 不做 / 改成别的**；
- 「不做」的当场移进「本期不做」并记一句理由；
- **拍板项同批弹一次**，别逐条弹。

---

## 收敛闸门（进 G3 之前自检）

- [ ] 基准段立了，清单每行指得回基准项
- [ ] 基准项每项被覆盖或显式标"本期不涉及 + 理由"
- [ ] "现状是什么"每一格有证据出处或「待实查」，没有凭印象写的
- [ ] 落点名字都钉到了真实的页 / 入口
- [ ] 逐条过了最小增量阶梯
- [ ] 方案概述四节齐，核心逻辑进了表格

**🛡️ G3 方案核对闸** —— 他审的是：**每一处改动落点对不对、要不要做**。

过闸后：`_index.md` 标记进入原型迭代，进步 4。
